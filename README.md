AELORIA — The Land Above the Clouds. A vintage travel poster for a place that does not exist: one great floating island with a rocky lighthouse town, a long ladder down to a smaller islet, a waterfall spilling off its edge into the cloud sea, and an airship arriving at golden hour. The name is set huge across the sky in mossy stone with a single tagline — no quotes, no ratings. The poster image was generated in-session with Muse's image pipeline from the reference artwork Lyso supplied for this bounty (his instruction: make it look exactly like that reference); `generate.py` records the provenance and deterministically sizes the 1600×1600 generation down to the submitted 1024×1024 PNG.

## Run it

```sh
python3 generate.py
```

That writes `entry.png` (1024×1024, 1,031,266 bytes, deterministic — two runs write byte-identical PNGs). `python3 main.py` writes the same image to `/output/entry.png` instead. No network, no clock, no randomness.
